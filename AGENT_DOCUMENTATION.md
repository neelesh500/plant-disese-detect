# AgriNet AI Agent Documentation\n\nThis document outlines the architecture and integration of the newly added Multimodal AI Agent into the plant disease detection system.\n\n\n## 1. Overview\nThe AI Agent supports both Voice (via WebSpeech API) and Text commands, enabling hands-free operation in agricultural environments.\n\n\n## 2. Capabilities\n- **Site Control**: The agent can autonomously trigger site features.\n- **Disease Analysis**: Initiates the inference engine automatically when instructed.\n- **Hardware Access**: Explicit access to the local camera module for direct structural imaging.\n- **Workspace Reset**: Clears the canvas and drops current sessions smoothly.\n\n\n## 3. Technology Stack\n- **Frontend**: Vanilla JS, WebRTC (`getUserMedia`), WebSpeech API.\n- **Backend Interface**: Bridges frontend commands non-destructively to the existing Python Flask API.\n\n\n## 4. Known Constraints\n- Camera support relies heavily on secure origin (HTTPS/localhost) capabilities.\n- WebSpeech API is primarily supported by Chromium-based browsers, graceful degradation should be considered.\n
