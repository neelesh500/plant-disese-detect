# AgriNet AI Agent Documentation\n\nThis document outlines the architecture and integration of the newly added Multimodal AI Agent into the plant disease detection system.\n\n\n## 1. Overview\nThe AI Agent supports both Voice (via WebSpeech API) and Text commands, enabling hands-free operation in agricultural environments.\n\n\n## 2. Capabilities\n- **Site Control**: The agent can autonomously trigger site features.\n- **Disease Analysis**: Initiates the inference engine automatically when instructed.\n
