# Plant Disease Dataset & Feature Research

This document outlines the optimal datasets and feature extraction methods for robust plant disease detection models.

## 1. Datasets (Sourced Primarily from Kaggle)

### A. New Plant Diseases Dataset (Augmented)
- **Source:** Kaggle
- **Details:** 87K+ RGB images, 38 classes (healthy & diseased leaves).
- **Use Case:** Best for baseline deep learning model training due to sufficient data augmentation.

### B. PlantVillage Dataset
- **Source:** Kaggle (Standard Benchmark)
- **Details:** ~54K images. Highly standardized.
- **Use Case:** Ideal for comparative analysis against existing research papers.

### C. PlantDoc Dataset
- **Source:** GitHub / Kaggle
- **Details:** ~2,500 real-world, non-laboratory plant condition images.
- **Use Case:** Crucial for improving model robustness in actual field deployments.

### D. Cassava Leaf Disease Dataset
- **Source:** Kaggle Competition Data
- **Details:** 21K+ images with heavy real-world noise.
- **Use Case:** Excellent for testing real-world model deployment capabilities across varying lighting.
